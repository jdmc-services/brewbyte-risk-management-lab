# BrewByte Cybersecurity Protection & AI Governance

Original, publicly shareable, static HTML learning pathway. Seven standalone lessons plus a capstone. All diagrams are authored inline SVG; no stock imagery, third-party scripts, external image requests, analytics, or backend.

## Safe installation

Upload **only the new `modules/cybersecurity-protection/` folder** into the existing `jdmc-services/brewbyte-risk-management-lab` repository, preferably in a feature branch. Do not overwrite any existing files. The folder includes `index.html`, seven module pages, `capstone.html`, and `assets/style.css` and `assets/lesson.js`.

After review and merge, visit: `https://jdmc-services.github.io/brewbyte-risk-management-lab/modules/cybersecurity-protection/`

**Optional navigation addition:** Add a link from the existing portal to `modules/cybersecurity-protection/index.html` only after testing the new pages. Do not replace the existing portal index.

## Validation checklist
- Open `index.html` and each module. Verify all links.
- Run both quiz questions on every page; verify answer rationales and score.
- Enter a synthetic worksheet and test the download.
- Check mobile layout, keyboard navigation and print.
- Confirm no external requests or real student data are collected.
- Merge only after reviewing the changed-files list: all changes should be **new files inside this folder**.

## Educational and safety boundaries
- No proprietary slide content, vendor trademarks as logos, or publisher assessment content.
- Product and framework names are examples for further independent study, not endorsements.
- No scanning or testing without authorization. No real student or employer data.
- Browser-based exercises are illustrative; they do not configure real security systems.
