Try it on your own Windows computer

These steps require no administrative privileges or software installation. If your computer is managed by a school or employer, follow its acceptable-use policy; use the simulator when access is restricted.

1. Operating system: Open Start → Settings → System → About. Find the Windows edition. In PowerShell, try Get-ComputerInfo | Select-Object WindowsProductName,WindowsVersion.
2. Processor: Press Ctrl + Shift + Esc → Performance → CPU. In PowerShell, try Get-CimInstance Win32_Processor | Select-Object Name,NumberOfLogicalProcessors.
3. Memory: Task Manager → Performance → Memory. In PowerShell, try Get-CimInstance Win32_ComputerSystem | Select-Object TotalPhysicalMemory. Note that the command reports bytes.
4. Storage: Settings → System → Storage. In PowerShell, try Get-Volume. Identify total space versus free space.
5. Network: Settings → Network & internet. In Command Prompt, run ipconfig. Do not post its results publicly.
6. Processes: Task Manager → Processes. In PowerShell, try Get-Process | Select-Object -First 10 Name,CPU. Compare how each interface presents running programs.

Think like a technician: A slow computer does not automatically need more RAM. Check resource utilization, available storage, background processes, network behavior, and the application's requirements before recommending a fix.

Cloud AI

Most computation happens on remote servers. The workstation needs suitable connectivity and must protect business data sent to the provider.

Local AI

Model processing happens on the device. RAM, CPU, GPU or accelerator, storage, model size, and power consumption can matter.
