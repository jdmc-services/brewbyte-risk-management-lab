Bits. Bytes. Binary.

BrewByte sends menus, photos and orders across a network. Start with the small units that represent that information, then connect them to file sizes and speeds.

Learn independently or with a team. This optional activity does not change your saved mission progress.

1 · Three ideas to remember

TermMeaningExample
Bit · bOne binary digit: 0 or 1.One of two possible states.
Byte · BEight bits.00000101 is one byte.
BinaryA base-two number system. Its position values double as you move left.Binary 101 represents decimal 5.

Computers use patterns of bits to represent numbers, text, images and more. Software interprets those patterns using an agreed format. Not every byte is a letter.

The capital letter matters: MB means megabytes; Mb means megabits. Mbps means megabits per second; MB/s means megabytes per second.

2 · Build a number with eight switches

Each position has a value. A 1 includes that value; a 0 leaves it out. Add the included values to find the decimal number.

The example starts at 5: include 4 and 1. Leading zeros keep the display at eight bits; they do not change its value.

Check the 13-order challenge

Use 8 + 4 + 1. The byte is 00001101, representing decimal 13. This is a simplified example of storing an order count, not a complete order message.

These eight switches represent an unsigned whole number from 0 to 255: 256 possible patterns. The switches are a learning model, not a picture of how every computer physically stores a bit.

3 · Convert bits and bytes

Bytes × 8 = bits. To go back, divide bits by 8.

2 bytes × 8 = 16 bits.

Fractional bytes in a conversion are a mathematical result. Stored files occupy whole bytes; for example, 1 bit is one eighth of a byte.

4 · Why this matters for uploads and downloads

BrewByte uploads a 10 MB menu photo using a 20 Mbps upload rate.

  1. Convert the file: 10 MB × 8 = 80 megabits.
  2. Divide by the upload rate: 80 ÷ 20 = 4 seconds.

That is an ideal estimate. Other traffic, protocol overhead and server or connection conditions can increase the time. For a download, use the download rate instead.

This lesson uses decimal units: 1 MB = 1,000,000 bytes and 1 Mb = 1,000,000 bits. Binary storage labels such as MiB are an optional later topic.
