Concept 1

Data, binary, and addresses

A bit is a 0 or 1; eight bits make one byte. Network addresses identify interfaces and destinations. IPv4 addresses use 32 bits; IPv6 uses 128 bits. A MAC address identifies a network interface on a local link, but can be spoofed.

BrewByte in practice

A backup file is measured in bytes while an Internet link is commonly advertised in bits per second.

Concept 2

LAN, WAN, and network equipment

A LAN connects nearby devices. A WAN connects sites across distance. Switches forward local Ethernet frames, routers connect IP networks, wireless access points provide radio connectivity, and firewalls enforce network policy.

BrewByte in practice

Connect the cafe register and receipt printer on a protected local network; connect four branches through provider services.

Concept 3

IP, DNS, and DHCP

IP addresses enable packet delivery. DHCP can assign addresses and related settings automatically. DNS translates domain names into resource records; DNS does not by itself establish trust.

BrewByte in practice

When a tablet cannot reach inventory.example, check link status, IP configuration, DNS, and service health in order.

Concept 4

Wireless security and segmentation

Separate guest and business traffic with appropriate network segmentation and access controls. Use current supported WPA security, unique credentials, and least-privilege management access.

BrewByte in practice

A guest browsing the menu should not be able to reach the payment terminals.

Concept 5

Cloud, virtualization, and containers

A virtual machine runs a guest operating system on virtual hardware. A container packages an application and dependencies while sharing a host kernel. Cloud services shift some infrastructure responsibility to a provider, not all security responsibility.

BrewByte in practice

BrewByte hosts an inventory application in a managed cloud service rather than buying a server for every store.
